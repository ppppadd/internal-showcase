# FreightGo · 跨境物流智能询报价系统 — 项目展示页

在线浏览：https://ppppadd.github.io/freightgo-showcase/

面向面试的项目展示页：一页讲清「问题 → 方案 → 人机协作 → 落地成果」，
并附**可点交互原型**（纯 CSS 实现，零 JS）与在线 Demo 入口（扫码 / 点链接）。

## 说明

- 页面内所有数值（价格、评分、比例）均为**示意值**，不含任何真实公司、供应商或价格数据。
- 交互原型仅演示界面与交互方式；真实系统读取底价库与规则库后，输出可逐条对账的报价单。
- 单文件自包含版（图片内嵌、可离线双击打开）另存于交付包中。
