# 海盟 · Nexus 内部推广展示页（线上版）

保宏境通（Nexus / Seawin）跨境物流智能询价系统 · 内部推广展示页线上版。

`index.html` 为单页展示页（视频外置），部署到 GitHub Pages，可直接通过链接访问，无需本地双击。

## 访问方式

仓库开启 GitHub Pages 后，访问：

```
https://ppppadd.github.io/<repo-name>/
```

## 文件说明

| 文件 | 说明 |
|---|---|
| `index.html` | 展示页主体（外置视频引用，约 788KB，首屏加载快） |
| `demo-price-compare.mp4` | 企微功能 demo · 价格对比 tab 演示视频（9s） |
| `demo-quote.mp4` | 企微功能 demo · 询报价 tab 演示视频（16.6s） |
| `demo-monitor.mp4` | 企微功能 demo · 价格监控 tab 演示视频（10.2s） |
| `demo-supplier.mp4` | 企微功能 demo · 供应商管理 tab 演示视频（14s） |

> 视频原为 base64 内嵌于 HTML（自包含离线可播，约 4.67MB），线上版改为外置 mp4 引用以加快首屏加载。内嵌自包含版保留于工作区 `media/保宏境通_内部推广展示.html`。
